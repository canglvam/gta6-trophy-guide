Leonida Trophy Guide: an offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade, a guide in our own words that cites its sources, a checklist saved in the browser with export and import, filters by kind and grade, a spoiler setting that hides story trophies until they are earned, and a roadmap to the platinum with the missable trophies flagged. Static files, no build step, no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve `app/` with any static file server — `app/index.html` is the entry point.
